# 多言語対応の整理

## 1. UI の文言（対応済み）

`src/lib/locales/` に言語ごとの辞書を置き、`src/lib/i18n.ts` がまとめる。`locales/ja.ts` がキーの定義元。どの言語にも全部のキーが必要で、欠けていると `npm test`（`test/locales.test.ts`）が失敗する（実行時には、欠けた文言を英語→日本語の順に補う）。

| 区分 | 言語（20） |
| --- | --- |
| 東アジア | 日本語、英語、中国語（簡体）、中国語（繁体）、韓国語 |
| 欧州 | スペイン語、ポルトガル語、フランス語、ドイツ語、イタリア語、ロシア語、トルコ語 |
| 南・東南アジア | インドネシア語、ベトナム語、タイ語、ヒンディー語、ベンガル語 |
| 右から左 | アラビア語、ウルドゥー語、ペルシア語（`<html dir="rtl">` で UI を反転。ページ上の描画は常に左から右） |

- 初期値はブラウザの言語設定（`navigator.languages`）から選び、上部バーのセレクトで切り替え、`localStorage` に保存する。
- 言語を足すときは `locales/<code>.ts` を作り、`i18n.ts` の `Lang`・`LANGS`・`DICT` に 1 行ずつ追加する。
- 多くの翻訳は機械翻訳で作ったもの。その言語を母語とする方の確認・修正を歓迎する（特にアラビア語・ウルドゥー語・ペルシア語・ベンガル語）。
- 画面のフォントは `system-ui` などシステムのフォントに任せているため、追加のフォント同梱は不要。

## 2. 既存テキストの表示・抽出と CMap

**CMap が要るのは日中韓（CJK）の非埋め込みフォントだけ**で、タイ語・アラビア語・ヒンディー語・ロシア語などには関係ない。

| 言語 | PDF 内の文字コードの持ち方 | 必要なもの | 現状 |
| --- | --- | --- | --- |
| 日本語・中国語・韓国語（フォント非埋め込み） | Adobe の定義済み CMap（`90ms-RKSJ-H`、`UniGB-UCS2-H`、`KSCms-UHC-H` など）で文字コード→CID | その CMap 表 | **全 CMap を同梱済み**（日中韓すべて、約 1.7 MB） |
| 日中韓（フォント埋め込み） | `Identity-H` か埋め込み CMap | 何もいらない | 対応 |
| タイ語・アラビア語・ヘブライ語・ヒンディー語・ロシア語など | フォントは埋め込まれ、`Identity-H` または 1 バイトのエンコーディング（WinAnsi、Differences など） | 何もいらない | 対応（表示・抽出・削除まで可） |
| 標準 14 フォント（非埋め込みの欧文） | WinAnsi など | AFM の幅表（pdf-lib に同梱） | 対応 |

**混在している場合**：PDF はフォントごとに文字コードの持ち方が決まる。1 ページに日本語（CMap）と英語（WinAnsi）とタイ語（Identity-H）が混ざっていても、pdf.js がフォント単位で必要な表を取りに来るので、同梱しておけば自動的に動く。アプリ側の行解析も命令ごとにフォントを見ているため、混在ページでも行ごとに正しく扱える。

**書き込み側**：タイ語・アラビア語・ヘブライ語・ヒンディー語・ベンガル語は、前後の字で形が変わる・記号が重なるなどの整形（シェーピング）が要る。同梱フォントで書くときは fontkit で整形し、使った字形だけを PDF に埋め込む（`src/lib/shape.ts`）。元の文字の書き換えでは、変えた語だけを同梱フォントで書き、ほかの字形は元のまま残す（`src/lib/anchoredEdit.ts`、右から左の行は `src/lib/rtl.ts`）。

## 3. 書き込み用フォント（パックと版）

`assets/fonts/fonts.json` がフォントとパックの定義。ビルドのときに `--fonts=<パック>` で同梱するフォントを選び（`scripts/build.mjs`）、実行時は文字の範囲と UI の言語から自動でフォントを選ぶ（`src/lib/fonts.ts` の `pickFont`）。

| パック | 同梱フォント | 書ける文字 |
| --- | --- | --- |
| `ja` | BIZ UDP ゴシック・明朝、Noto Sans・Serif、Noto Sans Thai / Arabic / Hebrew / Devanagari / Bengali | 日本語、欧文（ベトナム語を含む）、キリル、ギリシャ、タイ、アラビア、ヘブライ、ヒンディー、ベンガル |
| `latin` | Noto Sans・Serif | 欧文（ベトナム語を含む）、キリル、ギリシャ |
| `intl` | `latin` ＋ Noto Sans Thai / Arabic / Hebrew / Devanagari / Bengali | `latin` ＋ タイ、アラビア、ヘブライ、ヒンディー、ベンガル |
| `zh-CN` / `zh-TW` / `ko` | Noto Sans・Serif の SC / TC / KR | 簡体字中国語 / 繁体字中国語 / 韓国語、欧文 |

配布する版は 6 つ（`ja`・`en`（`intl` パック）・`zh-cn`・`zh-tw`・`ko`・`all`。`scripts/editions.mjs`）。どの版も機能と UI の言語（20）は同じで、違うのは書き込みに使えるフォントだけ。表示・ページ整理・注釈・墨消しは、どの版でも、どの言語の PDF にも使える。

- 同じ漢字でも日本語・中国語・韓国語で字形が違うので、`all` 版では UI の言語に合うフォントを先に選ぶ。
- 足した字が文書のフォントに無いときは、その語だけ（日本語・中国語・韓国語ではその字だけ）が同梱フォントになり、行のほかの部分は元のフォントのまま残る。
- フォントを足すときは、`assets/fonts/` にフォントとライセンス文を置き、`fonts.json` に定義を足して、`node scripts/licenses.mjs --write` を実行する。
