Components bundled inside @pdf-lib/fontkit

@pdf-lib/fontkit is distributed as a single pre-built file that contains the libraries below.
The exact versions are those resolved when that file was built; the license texts are taken from
the published packages. Node.js core-module shims (events, stream, string_decoder, util, inherits)
are included through rollup-plugin-node-builtins (ISC) and carry the licenses of the Node.js project (MIT)
and of inherits (ISC).
